SIH26147 · Signal intelligence, made inspectable

Raw signal files should not be a black box.

DEmod helps analysts move from bytes to evidence: format assumptions, spectra, bursts, modulation candidates, and a transparent path to supported bit recovery.

↗

A raw IQ capture can be huge, ambiguous, and full of signals that do not announce themselves. DEmod is built to expose what the data supports—and to show uncertainty where it does not.

01 / METHOD

Metadata first. Evidence second. Analyst judgement always.

03 / A useful boundary

We do not pretend every unknown waveform can be decoded.

DEmod distinguishes measured facts from model hypotheses. If capture metadata is missing or a bitstream is too weak, the output says so. That is how a signal-analysis tool earns trust.
